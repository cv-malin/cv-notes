# 数据标注：决定上限的一步

模型精度的上限由数据决定，数据质量的上限由**标注规范**决定。规范没写清楚，标注员只能凭理解猜，最后就是"同一个缺陷三种框法"。

## 1. 先定类别体系

### 原则

- **互斥**：一个目标只能落进一个类别。有歧义就拆成两个类别，别靠标注员自觉。
- **可判定**：给每个类别写一句"什么算、什么不算"，配 3~5 张正反例图。
- **粒度一致**：`划痕` 和 `浅划痕` 如果业务上不区分，就别分；分了就要有明确的判定阈值。
- **少而准**：类别越多，每个类别的样本越少，长尾越严重。

### 建议的表结构

| 字段 | 说明 |
| :--- | :--- |
| `name` | 英文标识，代码里用 |
| `display_name` | 中文名，标注界面显示 |
| `definition` | 一句话定义 |
| `include` | 什么算（附正例图） |
| `exclude` | 什么不算（附反例图） |
| `min_size` | 最小可标注尺寸（像素） |

`min_size` 非常重要：没有它，标注员会对 3×3 像素的噪点纠结半天，且不同人标准不一。

## 2. 框与掩码规范

### 检测框

- 紧贴目标**可见外轮廓**，不留白、不切边。
- 遮挡目标：按可见部分框，还是按推断完整轮廓框？**必须二选一写进规范**，并保持全数据集一致。
- 目标被图像边界截断：训练时通常保留但标记 `truncated`，评测时单独统计。
- 重叠目标：每个目标一个框，不做合并。

### 分割掩码

- 边界像素的归属：约定"包含边界内侧"或"按 50% 覆盖"，不要两种混用。
- 小目标掩码至少 3×3 像素，否则多边形退化。
- 多部件目标（如带线缆的工件）：明确线缆算不算目标的一部分。

### 难例与忽略区

- 设定 `ignore` 区域（如反光、遮挡板、传送带纹理），训练时排除，避免模型学错。
- 对"拿不准"的样本单独打 `hard` 标签，不要强行归入某类。

## 3. 标注流程

```
预标注（模型推理） → 人工修正 → 交叉质检 → 入库 → 版本快照
```

- **预标注**能把效率提升 2~5 倍，但必须人工逐帧确认：模型漏检的地方，标注员也容易漏。
- **交叉质检**：抽 5%~10% 由第二人复核，统计类别一致率（IoU > 0.5 视为一致）。一致率 < 90% 说明规范有歧义，先改规范再继续标。
- **入库**：图像、标注、规范版本三者绑定，任何一方变更都要留痕。

## 4. 数据划分

- 按**场景**划分而不是随机划分：同一批次、同一工位、同一天采集的图不能同时出现在训练集和验证集，否则指标虚高。
- 验证集要覆盖：正常品、各类缺陷、边界工况（光照变化、遮挡、不同批次）。
- 保留一份**从未参与训练和调参**的测试集，只在最终评估时用一次。

## 5. 常见问题

| 现象 | 根因 | 处理 |
| :--- | :--- | :--- |
| 验证集 mAP 很高，上线就崩 | 训练/验证同分布，测试集被污染 | 按场景/时间重新划分 |
| 同一缺陷标注框大小差异大 | 缺 `min_size` 与遮挡规则 | 补规范，重标冲突样本 |
| 模型对反光区域误检 | 反光区未标 `ignore` | 增加忽略区并重训 |
| 类别不平衡导致小类召回低 | 长尾 | 重采样 / 难例挖掘 / 调整 loss 权重 |
| 标注员之间一致性差 | 规范歧义 | 用一致率指标定位争议类别 |

## 6. 检查清单

- [ ] 每个类别都有定义、正例、反例、最小尺寸
- [ ] 遮挡、截断、重叠的框法已明确且全量一致
- [ ] 忽略区已标注并在训练中生效
- [ ] 抽检一致率 ≥ 90%，争议类别已澄清
- [ ] 按场景划分训练/验证/测试，测试集封存
- [ ] 图像 + 标注 + 规范版本号一起归档
