# cv-notes · 机器视觉工程笔记

把机器视觉项目里反复踩到的坑、反复验证过的流程，整理成可以直接照着做的笔记。

面向的不是"论文怎么读"，而是"项目怎么落地"：标定怎么验、模型怎么导、推理怎么快、标注怎么不乱。

## 目录

| 主题 | 文档 | 说明 |
| :--- | :--- | :--- |
| 相机标定 | [docs/01-calibration.md](docs/01-calibration.md) | 针孔模型、畸变、张正友标定、手眼标定、误差评估 |
| 模型部署 | [docs/02-deployment.md](docs/02-deployment.md) | ONNX 导出、TensorRT 构建、预处理/后处理一致性、性能调优 |
| 数据标注 | [docs/03-annotation.md](docs/03-annotation.md) | 类别体系、框与掩码规范、难例、质检与版本管理 |

## 约定

- 所有结论都标注前提：硬件、框架版本、数据集规模不同，结论可能不成立。
- 能给检查清单的，就不写"注意一下"。
- 数值是实测或量级估计，会写清楚是哪一个。

## 适用场景

工业缺陷检测、装配检测、字符识别、定位引导，以及通用的检测/分割任务。
